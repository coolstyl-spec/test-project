# เว็บเก็บผลงาน (Portfolio)

เว็บไซต์แสดงผลงานแบบ static — ไม่ต้องติดตั้งอะไร เปิด `index.html` ในเบราว์เซอร์ได้เลย

## ความสามารถ
- แสดงผลงานเป็นการ์ด เรียงจากปีล่าสุด
- กรองตามหมวดหมู่ และค้นหาจากชื่อ / คำอธิบาย / แท็ก
- คลิกการ์ดเพื่อดูรายละเอียดและลิงก์ผลงาน
- รองรับมือถือ และโหมดมืด (dark mode) อัตโนมัติ

## วิธีเพิ่มผลงาน
แก้ไฟล์ `works.js`:

1. แก้ข้อมูลส่วนตัวใน `PROFILE` (ชื่อ, ตำแหน่ง, อีเมล, ลิงก์)
2. เพิ่มผลงานใน `WORKS` ตามรูปแบบนี้:

```js
{
  title: "ชื่อผลงาน",
  category: "หมวดหมู่",      // หมวดหมู่ใหม่จะขึ้นเป็นปุ่มกรองอัตโนมัติ
  year: 2026,
  description: "รายละเอียดผลงาน",
  tags: ["แท็ก1", "แท็ก2"],
  image: "images/work.jpg",  // เว้นว่างได้ ระบบจะสร้างภาพปกให้
  link: "https://...",       // เว้นว่างได้
},
```

รูปภาพให้วางไว้ในโฟลเดอร์ `images/`

## เผยแพร่ออนไลน์ (ฟรี) ด้วย GitHub Pages
Settings → Pages → Source: Deploy from a branch → เลือก branch และโฟลเดอร์ `/ (root)` → Save
