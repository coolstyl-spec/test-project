# หีบแดนลับ

เกม idle RPG บนเว็บ ฮีโร่สู้บอสอัตโนมัติ ชนะแล้วได้หีบสุ่มไอเทม เอาของที่ได้มาสวมใส่และฝึกฝนเพื่อลุยด่านที่ยากขึ้น

## วิธีเล่น

```bash
npm start            # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
```

เกมใช้ ES modules จึงต้องเปิดผ่านเว็บเซิร์ฟเวอร์ (เปิดไฟล์ `index.html` ตรงๆ ไม่ได้) ไม่ต้องติดตั้งแพ็กเกจเพิ่ม

## ระบบในเกม

- **สู้บอสอัตโนมัติ** มีเวลาจำกัด 30 วินาที (บอสราชันย์ทุก 10 ด่านได้ 45 วินาที) ถ้าแพ้หรือหมดเวลา ฮีโร่จะถอยไปฟาร์มด่านก่อนหน้า กด "ท้าบอส" เพื่อลองใหม่
- **คุณสมบัติบอส** ว่องไว, แข็งแรง, โจมตีแรง, ความโกรธ, เกราะหนา, ฟื้นฟู ยิ่งด่านสูงยิ่งมีหลายอย่าง
- **สกิล 4 ตัว** ฟันสายฟ้า, กรงเล็บโลหิต, ปราการศิลา (ฟื้นเลือด), เก็บเกี่ยวไร้ความปรานี (แรงขึ้น 2 เท่าเมื่อบอสเลือดต่ำกว่า 30%) ปลดล็อกตามด่าน ใช้อัตโนมัติหรือกดเองก็ได้
- **หีบสุ่ม 4 ระดับ** ไม้, เงิน, ทอง, แดนลับ สุ่มไอเทม 6 ระดับความหายาก ตั้งแต่ธรรมดาถึงเทพ
- **อุปกรณ์ 6 ช่อง** อาวุธ, หมวก, เกราะ, แหวน, สร้อย, รองเท้า ของที่หายากกว่าได้ค่าสถานะเสริมมากกว่า
- **ฝึกฝน** ใช้ทองเพิ่มพลังโจมตี พลังชีวิต และคริติคอลแบบถาวร
- **เร่งความเร็ว** x1 / x2 / x3
- **เก็บความคืบหน้า** ในเบราว์เซอร์ และได้รางวัลระหว่างปิดเกม (สูงสุด 8 ชั่วโมง)

## โครงสร้างโค้ด

| ไฟล์ | หน้าที่ |
|---|---|
| `src/data.js` | ข้อมูลเกม: ความหายาก หีบ ช่องอุปกรณ์ สกิล คุณสมบัติบอส ค่าสมดุล |
| `src/engine.js` | ตรรกะเกมทั้งหมด ไม่แตะ DOM จึงทดสอบด้วย Node ได้ |
| `src/render.js` | วาดสนามต่อสู้และเอฟเฟกต์บน canvas |
| `src/ui.js` | สร้าง HTML ของแท็บและหน้าต่างป๊อปอัป |
| `src/main.js` | game loop, ปุ่มต่างๆ, การเซฟ |
| `test/engine.test.js` | เทสต์ของ engine |

## ทดสอบ

npm test
